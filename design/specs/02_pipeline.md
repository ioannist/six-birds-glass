## 2. Protocol register discipline

The register R_i realizes both F-I autonomy (A_AUT) and the `protocol_trap_honest` internalization:
- **Honest packages** (all headline certificates): the schedule phase needed to make the dynamics autonomous is part of X_i. For interface-based packages this is light: at a declared interface the register is a single declared value (e.g. `mid` carries R = {post_upjump}), because continuations out of the interface carry their own schedule inside the kernel. Use the minimal register that makes every declared kernel a genuine function of state only.
- **The `protocol_trap_naive` control** (GT4(a)): the same physics with the register omitted and per-leg kernels declared as if schedule bookkeeping were external. Its residue must vanish on the honest side.

## 4. Exact thermal witness constructions (the hard part)

A formal witness needs **exact** s⁰ equality. Expectations along thermal evolutions are rationals but generic exact matches never occur at integer steps. Three sanctioned constructions (all become *declared histories* — [A] histories are just declared rational distributions, so tuned constructions are legitimate provided they are declared and frozen):

### 4.1 Reflection pairs (structural, exact by symmetry)
East dynamics is left-right asymmetric (facilitation from the left wall); spatial reflection ρ(n)_i = n_{N+1−i} preserves any reflection-invariant panel exactly. Declare h = μ and h′ = μ∘ρ for any non-reflection-symmetric preparation μ (e.g. an aged quench state). With panel components restricted to reflection-invariant observables (E, interior adjacency count D = Σ_{i=1}^{N−1} n_i n_{i+1} — interior bonds only, never the wall bond n₀n₁; and NOT n_1), s⁰(h) = s⁰(h′) **exactly**, while futures differ (verify: some declared (γ, e) entry differs). This gives certificate-grade split pairs with a rich panel at zero tuning cost. File these as "structural Kovacs-class witnesses" — same-now/different-later on the declared panel.

### 4.2 Randomized-stop tuning (the Kovacs-moment construction)
A **randomized-stop kernel** K_θ := θ·(P_ε)^τ + (1−θ)·(P_ε)^{τ+1} with θ ∈ ℚ∩[0,1] is rational row-stochastic, hence an admissible declared continuation (physically: a protocol whose final hold duration is randomized between τ and τ+1). Because obs is affine in θ, for any single declared panel expectation (e.g. w_E) with a sign change between steps τ and τ+1, there is an **exactly computable rational θ\*** matching the target value. Construction of the Kovacs-moment history:
- Run `P_kovacs(t_w)` exactly to the bracketing steps around t_K on the ε_mid leg;
- Solve θ\*·⟨E⟩_τ + (1−θ\*)·⟨E⟩_{τ+1} = E_eq(ε_mid) in ℚ;
- Declare μ_K := θ\*·μ_τ + (1−θ\*)·μ_{τ+1} — its mean energy equals the ε_mid equilibrium value **exactly**.
- Witness pair: (μ_K, π_{ε_mid}) under the single-component panel {w_E}. For k-component panels, tune k mixture weights over k+1 bracketing distributions by solving the rational linear system — feasible iff the target panel vector lies in the **convex hull** of the candidates' panel vectors (solve exactly, then check all θ_j ≥ 0; an affine solution with negative weights would make μ_K a signed measure and K_θ non-stochastic, which is inadmissible). If the convexity check fails, report and fall back to the 1-component certificate + reflection pairs for rich panels.

### 4.3 The Kovacs loop ℓ_Kovacs (endo-continuation at `mid`)
Declare ℓ = K_θ ∘ (P_{ε_mid})^{τ_probe} ∘ (P_{ε_lo})^{t_w} ∘ (P_{ε_hi})^{τ_hot} ∈ 𝒞_{mid→mid} — heat, quench, age, return, with the final leg randomized-stop-tuned so that s⁰(push_ℓ μ_K) = s⁰(μ_K) **exactly** (same solve as §4.2 applied to the loop's last leg, including the same feasibility conditions: a bracketing/sign-change must exist across the candidate stop times and the solved weights must be nonnegative — verify both exactly; if infeasible at the default durations, extend the declared stop-time candidate set before declaring failure). Declare ℋ_mid ⊇ {μ_K, push_ℓ μ_K, π_{ε_mid}} (loop images pre-declared per §3). Target certificate ([A] §13.6 pattern): current loop score 0 (panel returns exactly), predictive loop score > 0 (some declared (γ,e) future entry moved — verify exact inequality). This instantiates Thm 3.6 / `loopAsymmetry_exhibits_movedPredictive_fixedCurrent`.

**Honesty note (file with artifacts):** tuned mixtures and randomized-stop kernels are declared package elements, disclosed as such; the claim is never "integer-step protocols hit exact equality" but "the declared catalog (which includes randomized-duration protocols) contains exact split pairs and panel-preserving loops." The lab shadow (GB10) maps these to finite-resolution panel matches.

## 5. Future-signature catalog (the declared probe list ℱ)

Freeze, per package: probe continuations γ = holds at each grid ε for each declared delay s ∈ S_probe (a short ladder, e.g. {1, 2, 4, …, 2^k} steps), each followed by the panel events at the target interface. The two-time response vector s⁺(h) is then exactly [A] eq `eq:future-signature`. Keep |ℱ| modest (tens): every entry multiplies certificate cost. The catalog must include at least one entry that separates each intended witness pair — verified at freeze time.

## 7. Robustness layer

Port [A] §11.4: deterministic perturbation bundles that jiggle numeric leaves (kernel entries, event weights) with exact renormalization, 20 trials, survival predicates per benchmark, thresholds 0.95 (cleanness) / 0.80 (persistence), predicate names `kovacs_persists` etc. Perturbations must respect the model class (perturb ε within the declared grid neighborhood or perturb declared weights — never break row-stochasticity or detailed-balance *of the declared perturbed model*; the bundle spec is frozen in configs).

## 9. Acceptance tests for this layer

1. Package validation rejects: non-stochastic rows, undeclared continuation references, events off Σ, histories not summing to 1 (all exact).
2. Vendored [A] originals (abstract, non-thermal) reproduce their published metric table ([A] digest §13 master table) bit-exactly — proves the port didn't break the engine.
3. `kovacs_wheel` certificate: witness ≥ 1, fiber ≥ 2, gap > 0, loop scores (0, >0), all Fractions.
4. Reflection-pair witness at N = 8 with panel (E, D): exact s⁰ equality asserted, s⁺ difference exhibited with the separating (γ,e) named in the artifact.
5. Tuning solver: θ\* exactness (re-substitute and assert Fraction equality); infeasibility path exercised on a synthetic case.
6. Determinism: two runs from the same config produce byte-identical artifacts.
