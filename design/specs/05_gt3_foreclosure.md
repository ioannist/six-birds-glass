# 05 — GT3: Foreclosure of Static Order Parameters (+ GB5 Repair Sweep)

**Claim (GT3).** On the audited class, while witnesses exist: (i) every readout factoring through the current lens fails to be future-sufficient; (ii) every future-sufficient abstraction factors uniquely through M on its reachable image — M is *the* canonical state; (iii) the static-order-parameter search space is counted and closed: a fixed lens f defines exactly 2^{|im f|} predicates, and the distinguishing predicate is provably not among them — witnessed **constructively**, not by generic counting.

**Anchors.** [A] Thms 3.3–3.4 + Lean uniqueness (`../reference/A_holonomy_memory.md` §6); F-III T14 `FixedInterfaceDefinabilityBound` (|Def(f)| = 2^{|im f|}); F-I Def. 17 (definability = factorization), `lem:count-definable`, T-FOR-01, T-FOR-02 **with its caveat** (generic counting is a proxy; the foreclosure must be witnessed constructively on the declared class — GT2's certificates provide the witnesses); F-IV F12 (No-Free-Distinction), F46 (Law–State Split), F11 (No-Overread). Field-facing shadow reported per F-II `prop:visibility`.

## 1. Part (i)+(iii): the constructive foreclosure sweep

Setting: interface `mid` of the certified GT2 package; declared lens f with image im f ⊆ Σ; a certified witness pair (h, h′) with s⁰(h) = s⁰(h′).

**Key logical step (make it explicit in code and artifact):** a *static order parameter* candidate is any readout φ factoring through the current lens, φ = g ∘ (current signature). Since h, h′ have equal current signatures, **every** such φ takes equal values on h and h′; but h, h′ have different futures (the separating (γ,e) entry). Hence no φ in the factoring class is future-sufficient. The sweep makes this quantitative and exhaustive:

1. Enumerate Def(f): all 2^{|im f|} predicates on the lens image (F-III T14 gives the exact count; F-I `lem:count-definable` the counting lemma). For `L_energy` at N=10, |im f| = 11 → 2048 predicates — enumerable. For `L_panel`, |im f| may be too large to enumerate; then the sweep runs on the **predicate class generated by declared panel components under a declared budget** (see GB5 class below) and the full-count statement stays at the T14 counting level with the constructive witness carried per generator — record both.
2. For each predicate φ (or generator), assert φ(s⁰(h)) = φ(s⁰(h′)) — trivially true, but *computed*, giving the ledger: 2048/2048 predicates fail to separate the witness pair while the future separates them. This is the "counted and closed" artifact: the distinguishing predicate is not in Def(f), constructively.
3. Emit T-FOR-02 instance: the witness's distinguishing readout exists only in the strict language extension (predicates over M), with the F-IV F12 filing: the distinguishing readout has Δ_dist ≠ ∅ and therefore demands **declared memory** — the TNM T_f, when it helps at all, is lawful only as declared memory (a step toward M), never as a static order parameter. F46 filing: only state/history-dependent readouts separate the two glasses.

## 2. Part (ii): canonicity of M

Computational exhibit + Lean anchor:
- Build several future-sufficient abstractions s (e.g. s = full future signature; s = future signature ⊕ redundant coordinates; s = injective relabeling) and compute the factor map Reach(s) → M explicitly, asserting uniqueness pointwise ([A] Thm 3.4 `futureSufficient_factorsThroughPredictiveQuotient_onReachable` + `futureSufficient_factorization_unique_onReachable`).
- Build a **non**-future-sufficient abstraction (the current lens itself, given witnesses exist) and exhibit the factorization failure (two histories, same s-value, provably different futures — the same witness pair again).
- Artifact records: the abstractions, the factor maps as explicit finite tables, the uniqueness assertion, Lean fidelity row.

## 3. GB5 — Repair-impossibility over the declared repair class

Upgrades [A]'s `coherent_candidate` (repairs "skipped") to **certified failure over a frozen finite repair class** (proposal GB5; F-II `def:threshold-attachment` quantifier discipline; F-IV F12's five lawful repair modes and F24's eight resolutions delimit what counts as a repair — see `../reference/foundations_IV.md`).

### 3.1 The declared repair class (freeze before GT2 runs; budget B declared)

| Repair type | Class members |
|---|---|
| **Lens refinements (currentization attempts)** | (a) all `L_Tf`-type single-scalar additions: for each declared scalar readout r in the catalog R_scalars = {T̂_f (grid-nearest fictive temperature), E², D, n_1, n_N, block-energy pairs (E_left, E_right)}, the refined lens f ⊕ r; (b) all pairs of scalars from R_scalars (budget B = 2 coordinates); (c) every coarsening-then-refinement within declared fiber partitions up to B fibers split. ### 3.2 The sweep

For each repair ρ in the class, rebuild the package under ρ and recompute the GT2 diagnostics. Repair "succeeds" iff witnesses = 0 ∧ gap = 0 ∧ max fiber = 1 ([A]'s currentization/flattening success conditions). Record per-ρ outcome in the **witness ledger**: for every failed repair, the surviving witness pair and its separating entry under ρ.

**Expected structure worth surfacing:** some single-scalar refinements will *reduce* MaxFiber without clearing it (the first buyback rung, GT5 cross-link); the ledger row records the before/after fiber sizes — this is the quantitative bridge between GT3 and GT5.

**Also run the positive control:** the `latent_memory_base/refined` thermal benchmark, where one declared refinement DOES clear the residue — proving the sweep can detect success (no vacuous impossibility).

### 3.3 Claim form

"No repair in the frozen class 𝑅 (hash …) clears the Kovacs candidate at budget B" — a finite conjunction, certified by exhaustive enumeration, exact arithmetic. Anything outside 𝑅 is explicitly non-claimed (conditional-reporting line in the artifact; the recognition-grade strengthening "no admissible repair exists at all" is NOT claimed, per proposal §6).
